# Forskin Asset Pack

This directory contains original project artwork generated for the Forskin dashboard mode. The visual language is fantasy organic machinery: weathered metal, charcoal, warm gold, muted verdigris, and abstract plant-like structures. It intentionally contains no gore, explicit anatomy, third-party artwork, or model-generated text.

All SVG artwork and procedural recipes are original. The artwork may be used, modified, and redistributed with this project under the project's license. `reference/forskin-mode-reference.png` is a generated implementation style board, not a supplied or third-party visual reference.

Run `node apps/dashboard/scripts/generate-forskin-assets.mjs` from the repository root to reproduce all WebP and PNG outputs and `ASSET-MANIFEST.json`.
