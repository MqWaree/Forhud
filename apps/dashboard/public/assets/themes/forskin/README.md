# Forskin Asset Pack

This directory contains original project artwork generated for the Forskin dashboard mode. The visual language is fantasy organic machinery: weathered metal, charcoal, warm gold, muted verdigris, and abstract plant-like structures. It intentionally contains no gore, explicit anatomy, third-party artwork, or model-generated text.

All SVG artwork and procedural recipes are original. The v4 organic shell and ornament files are original ImageGen-assisted project artwork curated against the operator-provided composition reference; every slogan and operational label remains live HTML. The artwork may be used, modified, and redistributed with this project under the project's license. `reference/forskin-mode-reference.png` is the bundled implementation style board, not the operator's source reference.

Run `node apps/dashboard/scripts/generate-forskin-assets.mjs` from the repository root to reproduce the procedural outputs, inspect the curated assets, enforce both byte budgets, and rebuild `ASSET-MANIFEST.json`.
